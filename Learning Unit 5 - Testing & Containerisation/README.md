# 🧪 Learning Unit 5 — Testing & Containerisation

In this learning unit, you will test the GameVault application and prepare it to run consistently across different environments using containerisation. You will implement automated testing for the backend and frontend, test the REST API using Postman and Newman, check code quality using ESLint, and containerise the application using Docker.

By the end of this learning unit, GameVault will support:

```text
Step 01 -> Automated Testing

Step 02 -> Postman & Newman:
- API collections
- Environment variables
- JWT authentication
- Automated API tests

Step 03 -> React Testing and ESLint:
- Frontend component testing
- User interaction testing
- Code quality checks

Step 04 -> Docker & Docker Compose:
- Backend container
- Frontend container
- MongoDB container
- Multi-container GameVault environment
