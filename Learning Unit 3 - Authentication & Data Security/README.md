# 🔐 Learning Unit 3 — Authentication & Data Security

In this learning unit, you will secure the GameVault backend by introducing user authentication, authorisation and persistent data storage. You will implement secure registration and login, protect sensitive routes, control access according to user roles, and connect the application to MongoDB.

By the end of this learning unit, the backend will support:

```text
Step 01 -> Registration, Login and JWT Authentication
Step 02 -> MongoDB Integration
Step 03 -> Role-Based Access Control (RBAC)
Step 04 -> Rate Limiting
```

The focus is on ensuring that users can securely access GameVault, passwords and authentication data are protected, application data is stored persistently, and users can only perform actions permitted by their role.
