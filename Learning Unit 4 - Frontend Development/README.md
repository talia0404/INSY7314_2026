# 💻 Learning Unit 4 — Frontend Development

In this learning unit, you will develop the GameVault frontend using React and connect it to the secure backend developed in the previous learning units. You will implement authentication, core user functionality and role-based administrative features while managing application state, navigation and communication with the REST API.

By the end of this learning unit, the frontend will support:

```text
Step 01 -> Register and Login

Step 02 -> Core User Features:
- Browse games
- View game details
- Personal collections
- Reviews
- User profiles

Step 03 -> Admin Dashboard
```

The focus is on building a functional, connected frontend where users can authenticate, browse and interact with games, manage their personal GameVault experience, and access functionality appropriate to their role.
